# apt で入れるパッケージの宣言。bootstrap が読む。macOS 側の ~/.Brewfile に対応する。
#
# **apt には Brewfile に相当する標準形式が無い。** サードパーティの `aptfile` や
# `equivs` のメタパッケージという手はあるが、道具を増やすほどの利点が無いので、
# 「1行1パッケージ・`#` はコメント」という素のリストにしてある。得たいのは
# フォーマットではなく「**宣言をスクリプトから分離する**」という Brewfile の性質。
#
# 棚卸しの方法(`brew leaves` の対応物):
#     apt-mark showmanual
# 手で入れたパッケージが出るので、このファイルとの差分を見る。
#
# ここに書くのは「**apt でしか入らない / OS に近い**」ものだけ。
# OS を跨いで同じ版が欲しい CLI は ~/.config/mise/config.toml に置く
# (そうしないと、このファイルと ~/.Brewfile に同じリストを二重に書くことになる)。
