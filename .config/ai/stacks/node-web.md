# Node / Web(個人開発)

`core.md` の上に載る、スタック固有の分。**プロジェクト固有の規約は各リポジトリの
`AGENTS.md` / `CLAUDE.md` が持つ**ので、ここに書くのは「どのプロジェクトでも
だいたい同じ」ものだけ。

## パッケージ管理

- **pnpm。`npx` で未インストールのパッケージを取りに行かせない** — npm の解決器が
  pnpm の張った node_modules と衝突して整合が壊れる(復旧は
  `CI=true pnpm install --frozen-lockfile`)。ツールは devDependency にして `pnpm exec`
- **override / resolutions には必ず上限を付ける。** `">=7.29.1"` は「将来の
  メジャーも可」と読まれる。脆弱性の下限は、メジャーを越えてよい許可ではない
- ランタイムは mise(`.tool-versions`)。**exact な patch を強制できるのは
  自分で制御している消費者だけ** — Vercel のような PaaS はメジャーしか選べない

## 検査の層

型検査もユニットテストも**構造的に見られないもの**がある。依存を更新したら
実ブラウザまで通すこと。

| 層 | 見えるもの | 見えないもの |
| --- | --- | --- |
| `tsc --noEmit` | 型 | ローダ・バンドラの挙動 |
| jest + RTL | 純粋ロジック、コンポーネント単体 | モックしている境界(SVG、fetch、DB) |
| Playwright | 実際に配信されるページ | 本番固有の設定 |

## フロント

- ユーザー向け文字列をハードコードしない(i18n 辞書)
- サーバ/クライアント境界を意識する。`cookies()` を上位で読むと
  静的レンダリングから外れるなど、**上に置いただけで全体に効く**ものがある
